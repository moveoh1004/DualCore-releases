# DualCore

YouTube 자막을 화면 위에. 선택형 AI 번역과 Mac 투명 자막을 지원합니다.

## 테스트 설치

**[전체 테스트 키트 다운로드](https://github.com/moveoh1004/DualCore-releases/releases/download/v0.3.12-beta.1/DualCore-Test-Kit-0.3.12.zip)**

압축을 풀고 `START-HERE.html`을 열면 됩니다. Chrome 확장 폴더와 Apple Silicon·Intel 통합 Mac 설치 DMG가 들어 있습니다.

[설치 안내](https://moveoh1004.github.io/DualCore-releases/install.html) · [릴리즈 페이지](https://github.com/moveoh1004/DualCore-releases/releases/tag/v0.3.12-beta.1) · [확장만 받기](https://github.com/moveoh1004/DualCore-releases/releases/download/v0.3.12-beta.1/DualCore-0.3.12-chrome.zip) · [Mac 앱만 받기](https://github.com/moveoh1004/DualCore-releases/releases/download/v0.3.12-beta.1/DualCore-Mac-0.3.12-universal.dmg)

확장은 웹 스토어 등록 전 테스트 배포본으로 Chrome 개발자 모드에서 설치합니다. Mac 앱은 macOS 13.5 이상을 지원하며 개발용 임시 서명입니다. Apple 공증은 받지 않아 첫 실행 시 시스템 설정에서 허용이 필요할 수 있습니다. GitHub의 Source code ZIP은 설치 파일이 아닙니다.

원문 자막에는 API 키가 필요 없습니다. AI 기능은 승인된 베타 계정의 제공량이나 본인 API 키의 결제·한도를 사용합니다. Mac은 DualCore Overlay에 필요한 음원 도구를 포함하고 앱과 함께 도우미를 시작·종료합니다. Windows에서는 동봉된 Start-Windows.cmd를 실행합니다. 현재 공개 베타의 AI 기능에는 로그인·이메일 인증과 승인된 베타 권한이 필요하며 개인 키만으로 우회할 수 없습니다.

0.3.5부터 설치 PC·폴더가 달라도 확장 ID가 유지됩니다. 0.3.4 이하에서 업데이트하면 기존 확장을 끄고 새 폴더를 로드한 뒤 기존 계정으로 다시 로그인하고 설정·Mac 앱 연결을 확인하세요.

## English

Download the complete test kit above and open START-HERE.html. It includes the unpacked Chrome extension and a universal Mac DMG. Enable Developer mode at chrome://extensions and load the DualCore-Extension folder. The optional Mac companion is ad-hoc signed, not notarized; first launch may require Open Anyway in macOS Privacy & Security settings.
