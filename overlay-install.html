투명 Mac 자막 앱

macOS 13 이상 · Apple Silicon / Intel. 배경과 제목 표시줄 없이 자막만 표시하는 선택형 보조 앱입니다.

배포 준비 중

현재 배포용 Apple 서명·공증을 준비 중입니다. 공개 설치 파일은 서명·공증 검증을 완료한 후 이 페이지에 제공합니다. 기본 PiP는 앱 없이 지금 사용할 수 있습니다.

설치 파일 공개 후 연결 방법

  1. 사용 중인 Mac에 맞는 ZIP을 내려받아 앱을 응용 프로그램 폴더로 옮깁니다.
  2. 앱을 실행하고 메뉴 막대의 자막 아이콘에서 연결 화면을 엽니다.
  3. Chrome의 DuelCore 설정에 6자리 연결 코드를 입력하고 앱 연결을 누릅니다.
  4. YouTube를 새로고침한 뒤 투명 자막 시작을 누릅니다.

이동·크기·복사

자막 영역을 드래그해 이동하고 가장자리·모서리를 잡아 크기를 변경합니다. 앱의 위치 잠금을 켜면 마우스 클릭이 아래 앱으로 통과합니다.
