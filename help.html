YouTube 자막을, 화면 위에.

DuelCore는 YouTube 자막을 별도 창으로 보여줍니다. Chrome 116 이상 데스크톱 환경에서 사용하세요. 투명 자막은 macOS 13 이상에서 보조 앱을 별도 설치해야 합니다.

기본 PiP

  1. YouTube 영상에서 CC 자막을 켭니다.
  2. 상단 YouTube 로고 바로 오른쪽의 자막 PiP 버튼을 누릅니다.
  3. 다른 작업을 하면서 자막을 봅니다. 창을 닫으면 종료됩니다.

다음 자막을 확보한 영상에서는 다음 줄을 흐리게 표시하고 순서가 오면 위로 이동합니다. 라이브·자막 없는 영상·YouTube가 아직 생성하지 않은 자막은 미리 불러올 수 없습니다. 기본 PiP의 창 테두리는 Chrome에서 관리합니다.

번역 사용

  1. 확장 아이콘을 눌러 설정을 엽니다.
  2. OpenAI 또는 Anthropic을 선택하고 본인 API 키를 입력합니다.
  3. 대상 언어와 원문+번역 표시를 선택하고 번역 사용을 켜서 저장합니다.
  4. 선택한 API 제공자 접근 권한을 허용합니다.

API 계정에 유효한 결제·한도가 필요하며 해당 제공자가 직접 청구합니다. ChatGPT·Claude 월 구독으로 API 비용을 충당할 수 없습니다. 429 오류는 제공자의 잔액·요청 한도를 확인하세요. 키는 문의 이메일로 보내지 마세요.

자막 소스와 미리 준비하기

설정에서 YouTube 자막 또는 AI 음성 인식을 선택합니다. YouTube 모드는 원문 언어와 사전 준비 구간(10·20·40초)을 선택할 수 있습니다. 제공된 자막을 읽고 최대 8개씩 미리 번역합니다. 처음에는 최대 1.6초 기다린 뒤 원문부터 표시하므로 영상 재생을 막지 않습니다.

AI 음성 인식

  1. 자막 소스를 AI 음성 인식으로 바꾸고 음성 인식 설정에 OpenAI API 키를 저장합니다.
  2. 원문+번역을 원하면 번역도 켜고 번역 제공자 키를 저장합니다. OpenAI 키는 함께 사용할 수 있습니다.
  3. YouTube에서 자막을 시작하면 소리 공유 화면이 열립니다.
  4. 전송 안내에 동의한 뒤 해당 YouTube 탭을 선택하고 탭 오디오 공유를 켭니다.
  5. 공유 화면을 열어 둔 채 YouTube로 돌아가 재생합니다.

약 8초의 소리를 모은 뒤 API로 인식·번역하므로 그 이상의 지연이 있습니다. 아직 재생되지 않은 소리를 미리 읽지는 못합니다. 준비된 자막은 시간 순서대로 표시합니다. 공유 중지 또는 자막 종료로 수집을 멈춥니다. AI 음성 인식과 번역은 모두 확장에서 처리하며 Mac 앱 없이 사용할 수 있습니다.

투명 자막

Mac 앱 설치·연결 안내. 기본 PiP는 Mac 앱 없이 동작합니다. 독점 전체화면 게임 등에서는 다른 앱 위 표시가 제한될 수 있습니다.

설정과 삭제

꾸미기·언어 설정은 확장 설정 페이지에서 변경합니다. 키 삭제 버튼으로 API 키를 지우고, 앱 연결 해제로 Mac 연결을 해제합니다. 전체 확장 데이터는 chrome://extensions에서 DuelCore를 제거해 삭제할 수 있습니다. 개인정보 처리 상세.
