베타 토큰으로 AI 이용

DualCore 가입·이메일 인증 후 베타 신청을 보내거나 초대 키를 등록하세요. 승인되면 개인 API 키 없이 AI 자막·번역을 사용할 수 있습니다. 사용량과 만료일은 계정에서 확인합니다.

일과 몰입을 이어가며, 배움의 흐름도 끊김 없이.

업무·게임 중에도 팟캐스트와 강의를 듣고, AI 자막과 번역으로 내용을 이해하세요. DualCore는 YouTube 자막을 별도 오버레이 창으로 표시해 오디오 중심 시청과 학습을 돕습니다. Chrome 116 이상 데스크톱 환경에서 사용하세요. 투명 자막은 macOS 13 이상에서 보조 앱을 별도 설치해야 합니다.

기본 PiP

  1. YouTube 영상에서 CC 자막을 켭니다.
  2. 상단 YouTube 로고 바로 오른쪽의 자막 PiP 버튼을 누릅니다.
  3. 다른 작업을 하면서 자막을 봅니다. 창을 닫으면 종료됩니다.

다음 자막을 확보한 영상에서는 다음 줄을 흐리게 표시하고 순서가 오면 위로 이동합니다. 라이브·자막 없는 영상·YouTube가 아직 생성하지 않은 자막은 미리 불러올 수 없습니다. 기본 PiP의 창 테두리는 Chrome에서 관리합니다.

클라우드 로그인

확장 설정 상단의 DualCore 계정을 열고 이메일과 10자 이상의 비밀번호로 회원가입하거나 로그인하세요. 계정은 클라우드에 저장되고 로그인 상태는 브라우저를 다시 열어도 유지됩니다. 로그아웃하면 현재 로그인 세션이 해제됩니다. 이메일 인증 안내가 표시되면 메일로 받은 6자리 코드를 입력하세요. 코드는 10분 동안 유효하며, 기존 계정은 인증 메일 보내기를 눌러 받을 수 있습니다. 비밀번호를 잊었다면 로그인 화면의 비밀번호 찾기를 누르고 가입한 이메일로 코드를 요청하세요. 받은 코드와 10자 이상의 새 비밀번호를 입력하면 변경됩니다. 변경 후에는 모든 기기에서 다시 로그인해야 합니다.

번역 사용

  1. 확장 아이콘을 눌러 설정을 엽니다.
  2. API 연결에서 본인 OpenAI API 키를 입력하고 키 연결을 누릅니다.
  3. 대상 언어와 원문+번역 표시를 선택하고 번역 사용을 켜서 저장합니다.
  4. 선택한 API 제공자 접근 권한을 허용합니다.

API 계정에 유효한 결제·한도가 필요하며 해당 제공자가 직접 청구합니다. ChatGPT·Claude 월 구독으로 API 비용을 충당할 수 없습니다. 429 오류는 제공자의 잔액·요청 한도를 확인하세요. 키는 문의 이메일로 보내지 마세요.

번역 용어집

설정의 번역 용어집을 열고 TXT 또는 MD 파일을 불러오세요. 예: DualCore → 듀얼코어, cooldown → 재사용 대기시간. 전문 분야 설명도 함께 적을 수 있습니다. 불러오기는 현재 내용을 교체하며, 편집 후 설정 저장을 누르면 YouTube 자막 번역과 AI 음성 자막 번역에 적용됩니다. UTF-8 형식, 최대 64KB·6,000자를 지원합니다. 내용 비우기 후 저장하면 적용이 해제됩니다.

모델 재학습이 아닌 번역 참고 자료입니다. 용어집은 브라우저에 보관하며 번역 요청마다 API로 함께 전송되므로 사용량이 늘어납니다. 용어 반영 정도는 모델과 문맥에 따라 달라집니다.

자막 소스와 미리 준비하기

설정에서 YouTube 자막 또는 AI 음성 인식을 선택합니다. YouTube 모드는 원문 언어와 사전 준비 구간(10·20·40초)을 선택할 수 있습니다. 제공된 자막을 읽고 최대 8개씩 미리 번역합니다. 처음에는 최대 1.6초 기다린 뒤 원문부터 표시하므로 영상 재생을 막지 않습니다.

AI 링크 자막

DualCore 계정에 로그인한 뒤 설정에서 AI 링크 자막을 선택하고 OpenAI 키를 연결해 저장합니다. 음원 추출은 Railway 서버의 yt-dlp와 FFmpeg가 실행하므로 컴퓨터에 별도 서버를 실행할 필요가 없습니다. PiP는 현재 영상 링크에서 음원을 추출해 재생할 앞 구간을 준비합니다. 원문이 먼저 표시되고 번역이 도착하면 갱신합니다. 최초 준비 중 잠시 멈춘 영상은 원문 준비 또는 오류 발생 시 재개합니다. 탭 소리 공유는 사용하지 않습니다. YouTube 접근이 차단되면 추출 오류를 표시하며 다른 수집 방식으로 전환하지 않습니다.

투명 자막

Mac 앱 설치·연결 안내. 기본 PiP는 Mac 앱 없이 동작합니다. 독점 전체화면 게임 등에서는 다른 앱 위 표시가 제한될 수 있습니다.

설정과 삭제

꾸미기·언어 설정은 확장 설정 페이지에서 변경합니다. 로그인 후 키를 한 번 저장하면 계정 서버에 암호화해 보관하며 다른 PC에서도 로그인하면 자동 연결됩니다. 로그아웃은 현재 기기의 키를 지우고, 연결 해제는 서버에 저장한 키도 삭제합니다. 로그인 전 저장한 키는 브라우저 세션에만 보관됩니다. 앱 연결 해제로 Mac 연결을 해제할 수 있습니다. 전체 확장 데이터는 chrome://extensions에서 DualCore를 제거해 삭제할 수 있습니다. 개인정보 처리 상세.
