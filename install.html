테스트 버전 설치 안내

처음에는 기본 PiP로 시작하세요. Mac 앱과 API 키 없이 자막을 확인할 수 있습니다.

1. Chrome 확장 설치

  1. 테스트 ZIP을 풀고 폴더를 문서 등 계속 보관할 위치로 옮깁니다.
  2. Chrome 주소창에 chrome://extensions를 입력합니다.
  3. 오른쪽 위 개발자 모드를 켜고 압축해제된 확장 프로그램을 로드를 누릅니다.
  4. 테스트 폴더 안의 DualCore-Extension 폴더를 선택합니다. 전체 테스트 폴더나 ZIP을 선택하지 마세요. 확장 ZIP만 받은 경우 manifest.json이 들어 있는 압축 해제 폴더를 선택합니다.
  5. YouTube를 새로고침하고 CC를 켠 뒤, 상단 YouTube 로고 오른쪽의 자막 PiP를 누릅니다.

Chrome 웹 스토어 등록 전 테스트 배포본이라 개발자 모드 설치가 필요합니다. 설치한 확장 폴더를 삭제하면 동작하지 않습니다. Windows·Linux에서는 기본 PiP를 사용하세요.

2. 투명 자막 — Mac에서 선택 설치

  1. 동봉된 DualCore-Mac-0.3.12-universal.dmg를 엽니다. Apple Silicon과 Intel을 모두 지원합니다.
  2. DualCore Overlay를 실행하고 처음 안내 창의 응용 프로그램에 설치를 누릅니다. 같은 창의 Applications로 직접 드래그해도 됩니다.
  3. 설치가 끝나면 응용 프로그램 폴더의 앱이 자동 실행됩니다. 이미 설치된 위치에서 실행하면 설치 안내는 나오지 않습니다.
  4. 첫 실행이 차단되면, 다운로드 출처를 확인하고 신뢰하는 경우에만 시스템 설정 → 개인정보 보호 및 보안 → 확인 없이 열기를 선택합니다. 회사·학교 관리 기기는 관리자의 정책에 따라 실행이 제한될 수 있습니다.
  5. 메뉴 막대의 자막 아이콘 → 앱 연결 및 위치 설정에서 숫자 6자리를 확인합니다.
  6. Chrome의 DualCore 설정 → Mac 앱 설치·연결을 펼쳐 코드를 입력하고 앱 연결을 누릅니다.
  7. YouTube를 새로고침하고 투명 자막 시작을 누릅니다.

이 테스트 앱은 개발용 임시 서명이며 Apple 공증을 받지 않았습니다. Apple의 실행 허용 안내. 시스템 전체 보안을 끄거나 터미널 명령을 실행할 필요는 없습니다.

3. AI 자막용 음원 도우미 — Windows / macOS

도우미는 테스트 키트에 함께 들어 있습니다.

  1. Mac에서는 DualCore Overlay를 실행하면 음원 도우미가 자동으로 함께 시작되고, 앱을 종료하면 도우미도 종료됩니다. 별도의 터미널 실행 파일은 필요하지 않습니다.
  2. Windows에는 네이티브 오버레이 앱이 없으므로 키트의 Start-Windows.cmd를 실행하고 창을 켜 두세요.
  3. Mac은 필요한 음원 도구가 앱에 포함되어 있어 추가 설치나 터미널 명령이 필요하지 않습니다. Windows에서는 시작 파일의 WinGet 설치 안내를 따르세요. 필요한 경우 Microsoft App Installer를 설치하세요.
  4. 확장 설정에서 AI로 자막 만들기를 선택하고 이 PC 연결 확인을 누른 뒤 연결 권한을 허용하고 저장합니다.
  5. YouTube에서 자막을 다시 준비합니다.

음원 준비는 항상 이 PC에서 실행됩니다. 도우미는 링크에서 필요한 음원 구간만 가져오고, 음원은 AI 음성 인식 서비스로 전송됩니다. 도우미 연결에 실패해도 서버 추출로 자동 전환하지 않습니다. 원문 YouTube 자막만 사용할 때는 도우미가 필요하지 않습니다.

4. 로그인과 AI 이용

확장 설정에서 DualCore 계정에 로그인하세요. 베타 참여 계정은 제공된 토큰으로 음성 인식·번역을 사용합니다. 현재 공개 베타의 AI 기능은 로그인·이메일 인증과 승인된 베타 이용 권한이 필요하며 개인 키로 우회할 수 없습니다. 서비스 정책에서 허용하는 개인 키 모드는 OpenAI API 키가 필요하며, 로그인 상태에서 저장한 키는 계정 서버에 암호화해 보관합니다. 사용자 번역 모델은 GPT-4.1 mini로 고정됩니다. 관리자가 지정한 베타 정책은 서버에서 적용합니다.

업데이트·삭제

앱은 종료한 뒤 새 DMG의 앱으로 교체합니다. 확장은 설치된 폴더의 내용물을 새 버전으로 교체한 다음 chrome://extensions에서 새로고침하고 YouTube도 새로고침합니다. 0.3.5부터는 설치 PC·폴더가 달라도 확장 ID가 같습니다. 0.3.4 이하에서 처음 업데이트하면 새 확장으로 인식될 수 있습니다. 새 폴더를 불러오고 기존 계정으로 로그인한 뒤 설정과 Mac 연결을 확인하세요. 이전 확장은 사용 중지해 중복 실행을 피하세요. 확장을 제거하면 브라우저에 저장된 설정이 삭제됩니다. 오버레이만 삭제하려면 메뉴 막대의 DualCore Overlay 삭제…를 사용합니다. 필요한 경우 설치된 앱 패키지 안의 Contents/Helpers/DualCore Uninstaller.app도 실행할 수 있습니다. 삭제 대상을 확인하고 연결 정보·창 설정도 삭제할지 선택하세요. 파일은 휴지통으로 이동합니다. Chrome 확장·계정·API 키는 유지됩니다. 확장도 삭제하려면 Chrome에서 별도로 제거하세요.

English quick start

From 0.3.5, the extension ID stays the same across PCs and folders. When upgrading from 0.3.4 or earlier, load the new folder, sign in with your existing account, check settings, pair the Mac app again, and disable the older extension. Extract the test kit to a permanent folder. Open chrome://extensions, enable Developer mode, choose Load unpacked and select DualCore-Extension. Reload YouTube, enable CC and click the caption button beside the YouTube logo. For optional Mac transparency, open the universal DMG, launch the app and choose Install in Applications in the first-launch dialog, or drag it to Applications yourself. The installed copy launches automatically. This beta is ad-hoc signed, not Apple-notarized: if macOS blocks it and you trust the source, use System Settings → Privacy & Security → Open Anyway. Pair the app’s six-digit code in extension settings. On Mac, DualCore Overlay automatically starts and stops the local audio helper; no separate Terminal launcher is required. On Windows, run Start-Windows.cmd and keep its window open because there is no native Windows overlay. The Mac app includes all required audio tools; no Homebrew, Terminal commands or separate runtime installation is needed. The Windows launcher provides WinGet guidance. Check the connection under AI caption settings and save. Audio extraction always runs on this PC. Sign in to DualCore; beta accounts use beta tokens. Personal-key mode uses your OpenAI API billing. To remove the overlay, use its menu-bar uninstall action. Review the app paths and optional connection/settings cleanup before confirming. Files go to Trash; the Chrome extension stays installed.
